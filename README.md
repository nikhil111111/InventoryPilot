# InventoryPilot

InventoryPilot is a full-stack inventory management system that helps businesses monitor inventory across multiple warehouses and generate intelligent reorder recommendations.

## Tech Stack

- Django
- Django REST Framework
- PostgreSQL
- React
- Axios
